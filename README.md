# API_ISLAM Data Organization

This project is dedicated to organizing Islamic data (Quran, Hadith, Adhkar, Prayer Times) in a structured format, suitable for building APIs or using in mobile applications.

## Directory Structure

- **`data/`**: The core data repository.
  - **`quran/`**: Everything related to the Holy Quran.
    - `surahs/`: JSON files for each Surah.
    - `translations/`: Quran translations in different languages.
    - `audio/`: Links or metadata for Quran recitations.
  - **`adhkar/`**: Collection of Adhkar (Morning, Evening, etc.).
  - **`hadith/`**: Hadith collections (Bukhari, Muslim, etc.).
  - **`prayer_times/`**: Data or calculation methods for prayer times.


## Getting Started

1. Place your JSON data in the corresponding folders under `data/`.
2. Use the `schemas/` to validate your JSON files.
3. Check `scripts/` for any data transformation tools.
