# Contributing to API_ISLAM

We welcome contributions to help improve and expand **API_ISLAM**!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```bash
   git clone https://github.com/your-username/API_islam.git
   cd API_islam
   ```
3. **Create a new feature branch**:
   ```bash
   git checkout -b feature/amazing-new-feature
   ```
4. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
5. **Run tests & validation**:
   ```bash
   python scripts/validate_data.py
   python -m pytest -v
   ```
6. **Commit your changes and submit a Pull Request (PR)**.

Thank you for helping share Islamic knowledge with the global developer community!
