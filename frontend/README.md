## ✨ المميزات والخصائص (Features)

* 📖 **المصحف الشريف (Al-Qur’an)**: قراءة السور، التصفح بالأجزاء، التصفح برقم الصفحة (604 صفحات)، وتشغيل التلاوات الصوتية.
* 🕌 **مواقيت الصلاة (Jadwal Sholat)**: حساب دقيق لمواقيت الصلاة اليومية بحسب الموقع الجغرافي.
* 🧭 **اتجاه القبلة (Kiblat Compass)**: بوصلة ذكية لتحديد اتجاه الكعبة المشرفة بدقة الزوايا.
* 🤲 **الأدعية والأذكار (Doa & Dzikir)**: أذكار الصباح والمساء (المأثورات الصغرى والكبرى)، وأدعية المناسبات اليومية.
* 📜 **الأحاديث النبوية (Hadits)**: استعراض الأحاديث النبوية الشريفة والحديث العشوائي اليومي.
* 📅 **التقويم الهجري (Kalender Hijriah)**: تقويم هجري وميلادي هجين مع المناسبات الإسلامية.
* 🎮 **ألعاب إسلامية تعليمية (Games)**: لعبة تخمين الآيات (Tebak Ayat)، تخمين السور (Tebak Surah)، ووصل الآيات (Sambung Ayat).
* 🌟 **اقتباسات وفيديوهات ملهمة (Quotes & Videos)**: مكتبة بطاقات دعوية وفيديوهات تحفيزية.

## 🚀 التشغيل المحلي (Quick Start)

### 1. تثبيت الحزم (Install Dependencies)
```bash
cd frontend
npm install
```

### 2. تشغيل سيرفر التطوير (Development Server)
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:4567` (أو المنفذ الذي يحدده Vite).

### 3. بناء نسخة الإنتاج (Production Build)
```bash
npm run build
```

## 🔗 الربط مع خادم API_ISLAM (Backend Connection)
يمكن ربط التطبيق مباشرة بـ endpoints الخاصة بـ **`API_ISLAM`** العاملة على:
`http://localhost:8000/api/v1`
للاستفادة من:
* نصوص المصحف الشريف بالروايات الـ 9 الرسمية لمجمع الملك فهد.
* موسوعة الكتب الستة في الحديث الشريف (34,100+ حديث).
* الحساب الفلكي لمواقيت الصلاة والقبلة.
